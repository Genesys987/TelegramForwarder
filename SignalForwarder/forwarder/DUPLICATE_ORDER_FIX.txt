DUPLICATE ORDER PREVENTION FIX
================================

PROBLEM IDENTIFIED:
- EA was processing the same signal multiple times
- Instead of 5 orders for 5 TP levels, 10 orders were created
- This happened because ReadSignalFile() was called on every tick
- Without proper duplicate detection, same GID was processed repeatedly

ROOT CAUSE:
1. ReadSignalFile() function ran on every tick
2. No tracking of already processed signals
3. Signal file deletion timing issues
4. No existing order verification before creating new ones

SOLUTION IMPLEMENTED:
====================

1. ADDED DUPLICATE TRACKING VARIABLES:
   - lastProcessedGroupId: Track last processed GID
   - lastProcessedTime: Track when signal was processed

2. DUPLICATE DETECTION IN ReadSignalFile():
   - Check if GID was recently processed (within 60 seconds)
   - Prevent same signal from being processed multiple times
   - Debug logging for duplicate detection

3. EXISTING ORDER VERIFICATION:
   - Before creating new orders, check if orders with same GID+Channel exist
   - If existing orders found: only update SL, don't create new orders
   - If no existing orders: create full order set

4. ENHANCED LOGGING:
   - Added "NEW signal" logging to distinguish fresh signals
   - Added duplicate prevention messages
   - Clear indication when orders already exist

CODE CHANGES:
=============

1. Global Variables Added:
   ```mql4
   int lastProcessedGroupId = -1;
   datetime lastProcessedTime = 0;
   ```

2. Duplicate Check in ReadSignalFile():
   ```mql4
   if(groupId == lastProcessedGroupId && currentTime - lastProcessedTime < 60) {
       Print("Signal already processed recently, skipping");
       return(false);
   }
   ```

3. Mark Signal as Processed:
   ```mql4
   lastProcessedGroupId = groupId;
   lastProcessedTime = TimeCurrent();
   ```

4. Existing Order Check in start():
   ```mql4
   // Check if orders with this GID already exist
   bool hasExistingOrders = false;
   for(int i=0; i<OrdersTotal(); i++) {
       // Check for existing orders with same GID+Channel
   }
   
   if(hasExistingOrders) {
       // Only update SL, don't create new orders
       UpdateExistingOrdersSL(...);
   } else {
       // Create new orders
       SendOrders(...);
   }
   ```
